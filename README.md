🏨 CodeAlpha_HotelReservationSystem

📌 Project Overview

The Hotel Reservation System is a Java console-based application developed as part of my CodeAlpha Java Programming Internship (4-Week Internship).

The project aims to simplify basic hotel room reservation operations, including searching for available rooms, booking rooms, viewing booking details, and cancelling reservations.

🎯 Project Objectives

Learn and apply Core Java concepts.

Practice methods, conditional statements, loops, and user input.

Understand Object-Oriented Programming (OOP).

Develop a menu-driven application.

✨ Planned Features

Search Available Rooms

Book a Room

View Booking Details

Cancel a Booking

Calculate the Total Room Cost

Display Booking Confirmation

Note: Features will be updated as development progresses.
